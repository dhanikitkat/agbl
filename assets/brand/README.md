# Logo warung

- `logo.jpg` — logo lingkaran Ayam Gepuk Bu Leny (dipakai di website)
- `logo-source.jpg` — file asli yang di-upload (boleh screenshot)

## Ganti logo

**Website:** ganti `assets/brand/logo.jpg` lalu commit/push.

**Drive (nanti):**  
1. Upload logo ke Drive, share Anyone with link  
2. Isi Settings `logo_url` dengan link Drive  
3. Script otomatis konversi ke URL gambar (sama seperti QRIS)

Kalau `logo_url` kosong, UI memakai `assets/brand/logo.jpg`.
